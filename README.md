# KayraPOS güncelleme kanalı

Bu depo, kasalardaki **KayraPOS Güncelle** programının yeni sürümleri indirdiği yerdir.

- `stable.json` — en güncel sürüm bilgisi. Ed25519 ile imzalıdır; imzası tutmayan dosya kasalarda kurulmaz.
- `updates/` — kurulum dosyaları.

Bu depoya müşteri verisi, lisans anahtarı veya imza anahtarı konmaz.
